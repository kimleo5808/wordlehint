# Wordle Trap Trainer 残局练习页

目标玩家是已经锁定四格、想练习如何用剩余回合分辨相似答案的人。公开路径为 `/wordle-trap-trainer`。一次练习提供一个固定词型、一个隐藏答案和三次有效猜测。首屏先让人做决定，提交后再给出这一手的实际反馈和可复算的分组。按路线图先开放三个词型；暂无本站用户重复练习的数据，需求强度待上线后验证。

## 逐页竞品调研

2026-11-19，使用公开英文网页搜索检索 `wordle trap trainer`、`wordle endgame practice four greens`、`wordle hard mode trap probe guess`。结果包含可玩的训练器、局中求解教练与文字攻略。目标是美国英语用户；搜索量、排名、AI 引用率未测。站点级 10 家横向研究见[路线图](../../../seo-expansion-research-2026-11.md)。

| 样本 | 页面做法 | 本页决策 |
|---|---|---|
| Don’t Wordle | 起始提供单空格残局、隐藏目标、规则选项、回合上限及分组。[训练器](https://dontwordle.app/wordle-trap-trainer/) | 用户第一猜之前只显示候选和局面，之后才展示对照。 |
| WordleSolver Pro | 在一盘进行中的游戏识别相似词，解释探测词如何拆分候选，也讨论剩余回合。[Strategy Coach](https://wordlesolver.pro/blog/wordle-trap-strategy-coach/) | 每次比较都锁定在该手之前的候选集合；区分实得反馈和最坏分支。 |
| TabGamer | 用相同词尾说明连续猜答案的风险，分别讨论普通和困难模式。[残局攻略](https://tabgamer.com/articles/escape-deadly-rhyme-trap-wordle/) | 准备一个中间缺字的局面，让玩家检验方法能否迁移。 |
| 玩家反馈 | 玩家讨论是否值得在困难模式下承受多个词共用四格带来的风险。[讨论](https://www.reddit.com/r/wordle/comments/1c9cl9z/hard_mode_traps/) | 承认同一策略可能输；明确“剩一个候选”和“已经猜中”的区别。 |

## 内容与首屏

核心词 **wordle trap trainer**，辅助意图为 `Wordle endgame practice`、`Wordle hard mode traps` 和 `Wordle probe word`。与局中 solver 和赛后 analyzer 互链。从复盘结果点击时，若累计绿格匹配已支持词型，直接进入相应训练；不传历史答案。

| 版位 | 用户问题 | 交付 |
|---|---|---|
| 首屏 | 还剩几个可能？下一个词猜什么？ | 四个已知格、醒目的空位、三次机会、规则和候选列表；手机先输入猜词。 |
| 提交之后 | 这步排除了多少？有保底效果吗？ | 真实反馈、每步前后词数、最近一步在同一候选池里的反馈分组和示范探测词分组。对照不透露隐藏词所属的假设分支。 |
| 第二屏 | 为什么四个绿格仍不够？ | 三种词型与词库口径表，LIGHT 与 FERNS 的分组图，普通/困难规则及最后一猜对照表。 |
| 回流 | 我的复盘里出现了这种局面吗？ | 已完成游戏连向 Analyzer；按需继续同一词型或换局。 |

可用于后测的问题有：四绿为何仍有九个候选、怎样算最差分支、只剩一手能否用探测词、困难模式为何拒绝词库里的词、第二格缺字能否用同一方法。本页分别用可复算的集合、原创图、决策表和训练情境回答。暂无 AI 平台实测。

视觉采用浅青纸色 #F2F7F6、深墨 #153B36、绿格 #27634C、琥珀空位 #F0D397、灰格 #505E67。标题用本站标题字，棋格用 IBM Plex Mono。大字空格棋盘是视觉中心；候选按字母顺序排列。手机单栏将提交动作置于候选和讲解之前。绿格、黄格和灰格同时提供读屏文字与符号。

```
词型 / 模式                 剩余候选
□ I G H T   三次机会         EIGHT FIGHT LIGHT …
输入猜测 / 提交             最近一手的分组比较
```

设计审阅后舍弃总分和“最佳手”排名。显示实际结果与每种反馈最多剩多少，允许玩家发现两个指标有时指向不同的选择。

## 验收

- 2026-06-17 的 2,315 个常见答案中，`_IGHT` 有 9 个、`_ATCH` 有 7 个、`S_ORE` 有 6 个，合法猜词库有 14,855 项。训练目标只从当前家族等概率抽取。四个绿格作为起始线索给定。
- 首手猜 LIGHT 在第一种家族分成 1 和 8，FERNS 分成 5 个单例和 1 组 4 个。困难模式必须保留全部已知绿位。因每个家族只剩一位未知，符合位置的猜词不可能得到黄色反馈。非法输入不耗回合；三手内必须实猜答案才能胜出。
- 重开、切换词型/模式均清空棋谱；猜中、耗尽、重复字母、词库外输入及普通模式探测词均有浏览器测试。记录入站练习点击、开局、完成和再次开局，不传用户猜词。
- 一页一个 H1，含 H2/H3/H4、至少三张表及原创配图。英文正文至少 1,500 词，完整主词次数除以正文词数为 1–3%。验证手机首屏、键盘、生产构建、canonical 与 sitemap。
